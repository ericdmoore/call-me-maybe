# Licensing

This repository contains two kinds of thing under two kinds of licence. The
split is deliberate: the software is permissive so it spreads, the audio is
handled separately so packs can be published under whatever terms their
author chooses.

## Summary

| What | Where | Licence |
|---|---|---|
| Source code | `cmd/`, `internal/`, `scripts/`, `Makefile` | Apache License 2.0 (`LICENSE`) |
| Asterisk config templates | `asterisk/` | Apache License 2.0 |
| Documentation | `docs/`, `README.md`, `CLAUDE.md` | Apache License 2.0 |
| Pack format specification | `docs/PACKS.md` | CC0 1.0 — implement it freely, no attribution needed |
| Bundled prompt text | `prompts/manifest.json` | CC BY-SA 4.0 |
| Bundled prompt audio | `prompts/build/*.wav` (generated) | CC BY-SA 4.0 |
| Third-party packs | not in this repository | whatever their author says |

When a file's licence is unclear, the repository-root `LICENSE` (Apache 2.0)
applies to code and this table governs everything else.

## Why Apache 2.0 for the code

Permissive, because installs are how the project spreads and any friction
there costs more than it protects. Apache rather than MIT for two specific
clauses:

- **Section 6 withholds trademark rights.** The code is free; the project
  name and the pack/archetype names are not. That distinction matters now
  that there is a brand attached.
- **Section 3 grants patents explicitly.** Standard defensive hygiene, and
  the reason most companies prefer Apache over MIT for anything they might
  depend on.

Copyleft was considered and rejected. AGPL protects against someone running
your software as a hosted service, which is not a risk here. GPL prevents
closed-source forks but does not prevent anyone selling an appliance, so it
would cost adoption without buying protection.

## Why the audio is licensed separately

Audio is the part that gets sold, so it needs terms of its own. Three tiers:

**The format specification is CC0.** Anyone may implement it, generate packs,
publish tooling, and sell the results without permission or attribution.
Community packs are the point.

**Bundled and community packs are CC BY-SA 4.0.** Share-alike keeps
derivatives in the commons. The default pack that ships with the repository
is under these terms, so a working reference implementation always exists and
nobody has to buy anything to run the system.

**Paid packs use a proprietary end-user licence**, not a Creative Commons
one. CC-NC is tempting for this and is a trap: its definition of
"non-commercial" is famously ambiguous, and a person running a home phone
from a home office should not have to reason about it. A short custom licence
— personal use in your own installation, no redistribution, no resale — is
clearer for a small download.

## Contributing

**No CLA.** A Contributor License Agreement grants the maintainer rights
beyond the project licence, and it is only needed for relicensing or dual
licensing. Neither is planned: this project stays Apache 2.0, and revenue
comes from audio produced separately rather than from the code. Apache 2.0
§5 already provides that contributions are licensed under the same terms
unless stated otherwise, which covers the ordinary case.

DCO sign-off (`git commit -s`) is welcome but not enforced. See
`CONTRIBUTING.md`.

## Third-party components

Two Go dependencies, both permissive:

- `github.com/BurntSushi/toml` — MIT
- `github.com/gorilla/websocket` — BSD 2-Clause

The system depends on Asterisk (GPLv2) but does not link against it — doorman
talks to it over ARI, a network protocol, as a separate process. That is an
arm's-length relationship, not a derived work.

Prompt audio built with `prompts/build.sh` uses piper, which ships permissive
voice models; check the licence of whichever voice you choose before
publishing a pack built with it. Audio generated by a commercial TTS service
is governed by that service's terms — see `docs/PACKS.md` for the specifics
that matter.

## Trademark note

"Call Me Maybe" is also the title of a 2012 song. Song titles are not
copyrightable and a software project sits in a different trademark class, so
the exposure is low — but it is not zero once branded goods are being sold.
The commercial side may be branded **Doorman** (already the binary's name)
to sidestep the question entirely.
