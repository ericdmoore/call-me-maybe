store.callmemaybe.cc
==============

An eComm site

- that sells files for "archetypal bouncers" 
- and other extension content
- jokes to be loaded
- stories to be loaded
- phone games to be played

The CLI easily helps integrate these file packages,
potentially with the help of the admin-users own LLM to help drive the CLI
